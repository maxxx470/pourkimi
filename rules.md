# Directives de remplacement et gestion des versions

1. **Vérification du code existant :**
   À chaque nouvelle commande accompagnant un mockup ou une spécification, vérifier systématiquement si du code ou un composant équivalent existe déjà dans le projet.

2. **Remplacement par le nouveau code :**
   Si du code existant correspond à la même fonctionnalité ou modification que la nouvelle commande, supprimer l'ancien code/composant et le remplacer intégralement par la nouvelle implémentation fournie.

3. **Discussion et alignement préalable :**
   Discuter et valider la compréhension des modifications avec l'utilisateur avant toute refonte majeure ou remplacement si nécessaire.
